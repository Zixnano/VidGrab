VIDEO GRABBER — FULL CHANGE LOG (all 7 original problems + 7 roadmap sessions)
================================================================================

ORIGINAL PROBLEMS
  1. Context menu/toolbar dead + selection vanished
     -> handlers read _current_ctx set from indexAt(pos); refresh() re-applies
        selection after each model reset; "Select a row first." on empty.
  2. Quality picker -> /probe-formats endpoint, format_id pass-through,
     Quality combo in AddDownloadDialog (background-thread probe + Signal).
  3. Recordings -> /upload endpoint; ArrayBuffer via service worker;
     <a download> kept as fallback.
  4. Auto-MP4: extensionless probed not skipped, stream check, output
     verified before deleting source, diagnostics logged; run_ytdlp outtmpl
     uses stem+" .%(ext)s", real filename resolved post-download.
  5. Launch speed: lazy tkinter imports; --onedir build.
  6. Settings dialog (4 tabs) via toolbar + File menu.
  7. Extensionless filenames: content.js sends real ext or omits; new_job
     falls back URL -> HEAD Content-Type -> default; one-shot migration in
     load_jobs_snapshot.

ROADMAP SESSIONS
  1. Sortable column headers (sort after filter+search, arrow indicators),
     search matches filename+category+status+URL, _selected_rows falls back
     to selectedIndexes (batch delete).
  2. Auto-pairing: POST /pair (localhost-only, once per session),
     pairIfNeeded() in background.js, Options "Test connection" button.
  3. Icon set: 7 SVGs in icons/ (concept: green arrow into tray on
     near-black rounded square) + ICONS.md with ICO conversion steps and
     the --icon=VideoGrabber.ico flag.
  4. Format picker on hover pill: "Download" menu with Best quality,
     probed formats, audio extraction (MP3/FLAC/Opus); server-side
     target_format support incl. FFmpegExtractAudio + maybe_convert_target.
  5. Popup overhaul: media-list manager (tabs, sizes, per-row actions,
     toolbar with Merge/Download/Copy/Toggle/Filter/Clear/Search);
     background.js captures Content-Length, addItem preserves real data,
     CLEAR_VIDEOS + GET_ALL_VIDEOS messages.
  6. Conversion progress: no console windows (CREATE_NO_WINDOW), /convert
     non-blocking with progress thread; GUI shows "conv N%" + WARN state.
  7. Cleanup: README onedir command, settings-load logging, error key
     excluded from snapshots, HEAD-ext cache cap.
