     -> handlers read _current_ctx set from indexAt(pos); refresh() re-applies

SESSION B — RECORDING CORRUPTION FIX:
  1. Upload bypasses chrome.runtime.sendMessage (~32MB cap truncated long
     takes). New nonce flow: background.js GET_UPLOAD_NONCE -> token-gated
     POST /upload-token -> content.js POSTs the blob DIRECTLY to /upload
     with a one-time X-Upload-Nonce header. Nonces: 128-bit, 5-min expiry,
     single use. Old UPLOAD_RECORDING handler removed.
     DEVIATION from handoff: CORS for /upload widened to any origin —
     content-script fetches carry the PAGE origin, not the extension's, so
     the original CORS config would have blocked every upload. Safe because
     /upload still requires the unforgeable nonce.
     SECOND DEVIATION (per DeepSeek's own verification item #4): content.js
     falls back to <a download> ONLY on nonce/network failure. A server
     rejection (corrupt recording) shows the error on the pill instead.
  2. _repair_recording(): ffmpeg remux with -fflags +genpts after save;
     original only replaced when the remux output verifies.
  3. _probe_recording(): ffprobe duration check before the job is marked
     done; corrupt uploads become error-status jobs and return HTTP 400.
     build-exe.yml / build_exe.md now bundle ffprobe.exe too.
  4. Upload/validated sizes logged.
  TEST: record ~2min blob video; log should show
  "recording upload (N bytes)" -> "recording repaired" ->
  "recording validated (M bytes)" -> "converted ... .mp4"; file plays in WMP.

SESSION C — SNIFFER, MODE PICKER, FINAL POLISH:
  1. Sniffer broadened: media ext regex now covers audio/image/doc/archive/
     programs; CT regex covers audio/*, image/*, office/zip/pdf types;
     "image"+"font" added to both webRequest listener type filters. Popup
     filter panel gained image/doc/archive/programs categories.
  2. Hover pill is now a mode picker: click always opens the menu; blob/MSE
     sources offer Record live + Send page URL (extractor sites); direct
     URLs offer Download file + Record live instead + Send page URL
     (extractor sites) + formats + audio extraction. Labels show the ▾.
  3. Startup port-in-use check: second instance logs and exits instead of
     opening a dead window.
  4. Filename collisions: stat_for renames to "name (2).ext" only when the
     job hasn't started (no .part, no bytes) — resume never renames.
  5. Download interception gated: known-ext only, skips localhost/raw IPs,
     one HEAD attachment-probe for extensionless URLs.
  6. Auto-shutdown cancelled (shutdown /a) when a new job queues within the
     60s window.
  7. Size-mismatch warning after generic downloads (logged + job error set,
     job still completes — CDNs misreport Content-Length).
  8. Stale .part cleanup at startup (older than 24h, no active job).
  9. jobs.json capped at 2000 entries (non-done always kept; in-memory
     pruning too). Atomic tmp+replace write preserved.
  10. Tray icon shows a green dot while any download is active, grey when
      idle (cached two-icon swap at 1Hz).
