Pair with Video Grabber

Pairing is usually automatic. If the extension can't reach the app, paste the token manually (in the desktop app: Tools → Copy pairing token for extension).

Off by default. When on, clicking any downloadable link in Chrome cancels the browser's own download and hands the file to Video Grabber instead. If another download manager's extension (IDM, for example) is also installed and enabled, it may grab the download first.
